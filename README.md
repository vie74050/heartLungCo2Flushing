# README #

## Unity Model Viewer ##

* Forked from Unity 2017.3.1f1 project for publishing WebGL model viewer for Heart Lung Machine.

## Asset Organization ##

Original assets and references on:

* [Heart-Lunch Machine Google Shared Drive](https://drive.google.com/drive/folders/0AHpT9Vj_MZZhUk9PVA) - FBX and dev sources. Requires membership to vpsimulation.com.
* [BCIT One Drive](https://bcit365-my.sharepoint.com/:f:/r/personal/vienna_ly_bcit_ca/Documents/_SOH/Heart%20Lung%20Machine/Reference%20Materials?csf=1&web=1&e=BcY0Zh) - Resources for reference shared by SMEs

## This version has ##

* parts list for selecting/deselecting model parts, dragable parts, transparency view
* updated WebGL template (D2L edit-mode compatible)
* ability to specify activity task, and task steps for assembly / disassembly (need to test this)
* ability to add linked items (parts list item clicked, can select additional items not in task list)
